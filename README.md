# 專案啟動說明

本專案使用 Node.js 版本 **23.11.0**，並使用 **pnpm** 作為套件管理器。

## 啟動方式

1. **安裝依賴** (如果您尚未安裝):
   ```bash
   pnpm install
   ```

2. **啟動開發伺服器**:
   ```bash
   pnpm run dev
   ```

   伺服器預設運行於 `http://localhost:3000`。

3. **建置專案 (生產環境)**:
   ```bash
   pnpm run build
   ```

4. **啟動生產伺服器**:
   ```bash
   pnpm run start
   ```
